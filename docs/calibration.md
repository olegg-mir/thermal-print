# Калибровка MX10 / MX10 calibration

1. Полностью зарядите принтер и вставьте непрерывную термоленту. Печатная область профиля — 384 точки (около 48 мм при 8 точках/мм).
2. В разделе **Настройки** подключите MX10 и нажмите **Пробная печать**. Эта этикетка содержит рамку, название и текущую дату.
3. Если начало этикетки выглядит бледным или обрезано, увеличьте число пустых строк **перед** этикеткой. Если нижний край остаётся в принтере, увеличьте строки **после**.
4. Значения по умолчанию после проверки пользователем: плотность **65535**, 5 пустых строк перед этикеткой и 100 после. Для чрезмерно тёмной печати уменьшайте плотность небольшими шагами. Уже сохранённые параметры остаются прежними; кнопка **Применить значения MX10** в настройках применяет новые значения.
5. Если вывод прерывается, проверьте заряд и уменьшите размер BLE-пакета либо увеличьте паузу между пакетами. Значения по умолчанию — 160 байт и 20 мс.
6. Сохранённые настройки относятся к текущему браузеру. Экспортируйте копию после удачной калибровки.

MX10 обычно не продвигает бумагу надёжно отдельной командой подачи. Thermal Print печатает пустые строки **внутри** задания. Для каждой копии соединение создаётся заново, а после передачи приложение ждёт 3 секунды, пока буфер принтера освободится. Если после сворачивания приложения соединение стало неактивным, нажмите **Подключить снова**. При остановке задания с `0xe` проверьте состояние принтера и заряд, затем переподключите его и повторите печать вручную. Код не повторяет частично отправленное задание автоматически. Поведение протокола основано на [практических измерениях MX10](https://github.com/s8n/cataclysm/blob/main/docs/mx10-cat-printer-research.md).

## English summary

Charge the MX10, use a continuous roll, then print the built-in test label. Adjust blank rows before/after the label for margins and change density in small steps. If transfers stop, try smaller BLE packets or a longer packet delay. Confirm final results on actual paper.
